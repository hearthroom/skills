# Hearthroom Sample Calibrator

Compare a draft to the closest synthetic sample by structure and name the
missing craft layer. The output is a calibration packet, not final fields and
not permission to copy sample prose.

## Required references

- `../../references/sample-driven-calibration.md` first.
- `../../examples/sample-card-packets.md` to pick the closest sample.
- `../../references/quality-scorecard.md` when the author asks whether the
  calibrated draft is strong enough.
- The narrow archetype reference only after the missing layer is known.

## Workflow

1. Classify the request: example-seeking, draft comparison, or copy-risk review.
2. Pick one primary sample and, only for a specific missing layer, one overlay.
   Never average several samples into a hybrid.
3. Compare by structure: primary contract, promise surface, durable engine,
   opening proof, voice proof, longplay proof, field allocation, play probes,
   originality.
4. State exactly which structure may be borrowed (field allocation, pressure
   shape, player agency, opening proof, probe type) and which text and details
   must not be reused.
5. Run the copy-risk check: names, places, artifacts, scene sentences, dialogue
   rhythm, tag sets, summary structure with nouns swapped, route or schema
   labels.
6. Name the missing layer and the repair order.

## Hand-off

```text
Request; selected sample; overlay
Card shape; structure borrowed, not text
Draft strengths; draft gaps; copy-risk check
Missing layer; repair skill order
Field allocation changes; opening proof changes; play probes to keep
Next skill
```

- `hearthroom-premise-workshop`: no premise yet.
- `hearthroom-archetype-director`: card type unclear.
- `hearthroom-card-blueprint` or the narrow archetype skill: structure missing
  before fields.
- `hearthroom-originality-adapter`: renamed-copy risk remains.
- `hearthroom-card-author`: ready for field assembly.
- `hearthroom-quality-auditor`: the author wants a score or the first repairs.

## Do not

- Do not copy sample names, scene text, voice lines, tag strings, route names,
  resource labels, or schema labels.
- Do not attach origin or performance claims to samples; they are synthetic
  teaching fixtures.
- Do not produce a second generic checklist; give specific allocation advice.
- Do not run CLI commands or edit the folder from this skill.
